## 🎯 转向参数计算

### 最大转向角

根据阿克曼几何，设置最大转向角为 **45度** (0.785 rad)

```
理由：
- 舵机可以转动 0-180度
- 中位 90度 = 直行
- 左转最大: 90° - 45° = 45度
- 右转最大: 90° + 45° = 135度
```

### 最小转弯半径

根据阿克曼转向几何计算：

```
R_min = L / tan(δ_max)
     = 0.17m / tan(45°)
     = 0.17m / 1.0
     = 0.17m ≈ 17cm
```

实际配置为 **0.30m (30cm)** 以留有安全余量。

## 🔧 舵机脉宽映射

### 标准舵机 (0-180度)

```
角度 → 脉宽映射:
  0°   → 500us   (理论值)
  45°  → 1000us  (左极限，实际使用)
  90°  → 1500us  (中位，直行)
  135° → 2000us  (右极限，实际使用)
  180° → 2500us  (理论值)
```

## 📊 速度与转向关系

### 阿克曼转向公式

```
转向角 δ = atan(ω × L / v)

其中:
- δ: 前轮转向角 (rad)
- ω: 角速度 (rad/s)
- L: 轴距 (m) = 0.17m
- v: 线速度 (m/s)
```

### 示例计算

#### 例1: 慢速左转
```
输入: v = 0.3 m/s, ω = 0.5 rad/s
计算: δ = atan(0.5 × 0.17 / 0.3)
     = atan(0.283)
     = 0.276 rad ≈ 15.8度

舵机脉宽: 1500 - (15.8/45) × 500 = 1324us
```

#### 例2: 中速右转
```
输入: v = 0.5 m/s, ω = -1.0 rad/s
计算: δ = atan(-1.0 × 0.17 / 0.5)
     = atan(-0.34)
     = -0.327 rad ≈ -18.7度

舵机脉宽: 1500 + (18.7/45) × 500 = 1708us
```

#### 例3: 最大转向
```
输入: v = 0.2 m/s, ω = 1.5 rad/s
计算: δ = atan(1.5 × 0.17 / 0.2)
     = atan(1.275)
     = 0.904 rad ≈ 51.8度

限制后: δ = 45度 (MAX_STEERING_ANGLE)
舵机脉宽: 1000us (左极限)
```

## 🔍 故障排查

### 问题1：小车转向方向相反

```c
// 在 ROS2Protocol.c 中修改
// 找到这行:
steering_angle = atan2f(angular_vel * WHEELBASE, linear_vel);

// 改为:
steering_angle = -atan2f(angular_vel * WHEELBASE, linear_vel);
```

### 问题2：转向角度不够

1. 检查 `MAX_STEERING_ANGLE` 是否太小
2. 检查 `SERVO_LEFT_MAX` 和 `SERVO_RIGHT_MAX` 范围
3. 检查机械结构是否有限制

### 问题3：舵机抖动

1. 减小舵机响应时间：
```c
ServoSetPluseAndTime(0, angle, 300);  // 改为 300ms
```

2. 添加死区：
```c
if(fabs(angular_vel) < 0.05f) {
    steering_angle = 0.0f;  // 小于阈值时保持直行
}
```

### 问题4：速度不准确

1. 检查轮子直径是否准确测量
2. 检查电机速度映射函数
3. 考虑地面摩擦系数影响

## 📐 理论计算验证

### 转弯半径验证

```
最小转弯半径 R_min = L / tan(δ_max)
                   = 0.17 / tan(45°)
                   = 0.17 / 1.0
                   = 0.17m

实际测试：
让小车以最大转向角行驶一圈，测量圆的直径
理论直径 = 2 × R_min = 34cm
```

### 角速度验证

```
角速度 ω = v / R
         = v × tan(δ) / L

例如: v = 0.3 m/s, δ = 45°
     ω = 0.3 × 1.0 / 0.17
       = 1.76 rad/s

这是理论最大角速度
```

```c
    float normalized = vel_ms / MAX_LINEAR_SPEED;
    
    // 使用平方根曲线，提高低速精度
    if(normalized > 0)
        normalized = sqrtf(normalized);
    else if(normalized < 0)
        normalized = -sqrtf(-normalized);
    
    int8 speed = (int8)(normalized * 100.0f);
```

### 2. 转向平滑处理

```c
// 添加转向角度滤波
static float last_angle = 0.0f;
float alpha = 0.3f;  // 滤波系数

steering_angle = alpha * steering_angle + (1 - alpha) * last_angle;
last_angle = steering_angle;
```

### 3. 速度自适应

```c
// 转向时自动降速

}
```
