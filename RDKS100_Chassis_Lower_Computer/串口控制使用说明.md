# 阿克曼底盘串口控制使用说明

## 功能概述

通过串口发送简单的指令来控制阿克曼底盘的运动，包括前进、后退、左转、右转和停止。

## 硬件连接

- 串口: USART1 (PA9-TX, PA10-RX)
- 波特率: 9600
- 数据位: 8
- 停止位: 1
- 校验位: 无

## 命令格式

### 基本命令（使用默认参数）

| 命令 | 功能 | 默认参数 |
|------|------|----------|
| `W` | 前进 | 速度 50 |
| `S` | 后退 | 速度 40 |
| `A` | 左转 | 速度 40, 转向程度 70 |
| `D` | 右转 | 速度 40, 转向程度 70 |
| `X` | 停止 | - |

### 带参数命令

| 命令格式 | 功能 | 参数范围 | 示例 |
|----------|------|----------|------|
| `Wxx` | 前进，指定速度 | 0-100 | `W50` (速度50前进) |
| `Sxx` | 后退，指定速度 | 0-100 | `S30` (速度30后退) |
| `Axx` | 左转，指定转向程度 | 0-100 | `A70` (转向程度70左转) |
| `Dxx` | 右转，指定转向程度 | 0-100 | `D80` (转向程度80右转) |
| `Txxxx` | 设置舵机角度 | 1000-2000 | `T1500` (舵机回中位) |

## 使用示例

### 1. 基本运动控制

```
W      // 前进（默认速度50）
X      // 停止
S      // 后退（默认速度40）
X      // 停止
A      // 左转（默认参数）
X      // 停止
D      // 右转（默认参数）
X      // 停止
```

### 2. 自定义速度控制

```
W80    // 高速前进（速度80）
W30    // 低速前进（速度30）
S50    // 中速后退（速度50）
```

### 3. 精确转向控制

```
A50    // 小幅度左转（转向程度50）
A100   // 最大幅度左转（转向程度100）
D30    // 小幅度右转（转向程度30）
```

### 4. 舵机角度控制

```
T1000  // 舵机左极限
T1500  // 舵机中位（直行）
T2000  // 舵机右极限
```

## 参数说明

### 速度参数 (0-100)
- 0: 停止
- 1-30: 低速
- 31-60: 中速
- 61-100: 高速

### 转向程度 (0-100)
- 0: 直行（不转向）
- 1-40: 小幅度转向
- 41-70: 中等转向
- 71-100: 大幅度转向

### 舵机角度 (1000-2000us)
- 1000: 左极限（约45度）
- 1500: 中位（90度，直行）
- 2000: 右极限（约135度）

## 串口调试工具设置

推荐使用以下串口调试工具：
- 串口助手
- PuTTY
- Tera Term
- Arduino Serial Monitor

设置参数：
- 波特率: 9600
- 数据位: 8
- 停止位: 1
- 校验位: 无
- 发送格式: ASCII
- 结束符: 回车换行 (CR+LF) 或 回车 (CR)

## 注意事项

1. 每条命令后需要发送回车符（\r）或换行符（\n）
2. 命令不区分大小写（W 和 w 效果相同）
3. 命令长度不超过8个字符
4. 参数超出范围会自动限制到有效范围
5. 舵机角度必须在1000-2000之间，否则会被忽略

## 代码集成

### 文件说明

- `SerialControl.c/h`: 串口控制模块
- `main.c`: 主程序，已集成串口控制
- `Usart.c`: 串口中断处理，调用串口控制函数

### 初始化流程

```c
// 系统初始化
SystemInit(); 
NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
InitDelay(72); 
InitTimer2();
IIC_init();
Usart1_Init();        // 串口初始化
InitLED();

// 阿克曼底盘初始化
AckermannInit();

// 串口控制初始化
SerialControlInit();
```

### 主循环

```c
while(1)
{
    DelayMs(20);              // 20ms延时
    ServoPwmDutyCompare();    // 舵机PWM更新
}
```

## 扩展功能

如需添加新的控制命令，可在 `SerialControl.c` 的 `ExecuteCommand()` 函数中添加新的 case 分支。

示例：添加原地旋转命令

```c
case 'L':  // 原地左旋
case 'l':
    printf("Spin Left\r\n");
    AckermannTurnLeft(30, 100);
    break;
    
case 'R':  // 原地右旋
case 'r':
    printf("Spin Right\r\n");
    AckermannTurnRight(30, 100);
    break;
```
