## 系统概述

### 硬件组成
```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  STM32F103RB 主控板                                 │
│    ├─ PB5  ────────→ 舵机信号线                    │
│    ├─ PB6  ────────→ I2C SCL                       │
│    ├─ PB7  ────────→ I2C SDA                       │
│    ├─ PA9  ────────→ 串口 TX（可选）               │
│    ├─ PA10 ────────→ 串口 RX（可选）               │
│    └─ GND  ────────→ 公共地                        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 主要外设
1. **舵机** - 转向控制
2. **I2C 电机驱动器** - 4 个电机控制
3. **USB 转 TTL** - 串口调试（可选）

## 主控板接线

### STM32F103RB 引脚定义

| 引脚 | 功能 | 连接设备 | 说明 |
|------|------|----------|------|
| **PB5** | TIM3_CH2 (PWM) | 舵机信号线 | 舵机控制 |
| **PB6** | I2C1_SCL | I2C 时钟线 | 电机驱动器 |
| **PB7** | I2C1_SDA | I2C 数据线 | 电机驱动器 |
| **PA9** | USART1_TX | USB转TTL RX | 串口发送 |
| **PA10** | USART1_RX | USB转TTL TX | 串口接收 |
| **GND** | 地线 | 公共地 | 所有设备共地 |
| **5V** | 电源 | 舵机电源 | 5V 输出 |
| **3.3V** | 电源 | 传感器电源 | 3.3V 输出 |

### 引脚位置图
```
STM32F103RB 开发板
┌─────────────────────────────────────┐
│                                     │
│  [USB]                              │
│                                     │
│  PA9  ●  ← USART1_TX                │
│  PA10 ●  ← USART1_RX                │
│  ...                                │
│  PB5  ●  ← TIM3_CH2 (舵机)          │
│  PB6  ●  ← I2C1_SCL                 │
│  PB7  ●  ← I2C1_SDA                 │
│  ...                                │
│  GND  ●  ← 公共地                   │
│  5V   ●  ← 5V 输出                  │
│  3.3V ●  ← 3.3V 输出                │
│                                     │
└─────────────────────────────────────┘
```

## 舵机接线

### 标准舵机（3 线）

#### 接线方式
```
舵机                    STM32F103RB
┌──────────┐           ┌──────────┐
│          │           │          │
│  信号线  │ ─────────→│   PB5    │  (黄色/白色/橙色线)
│  (黄/白) │           │          │
│          │           │          │
│  电源线  │ ─────────→│   5V     │  (红色线)
│  (红)    │           │          │
│          │           │          │
│  地线    │ ─────────→│   GND    │  (黑色/棕色线)
│  (黑/棕) │           │          │
│          │           │          │
└──────────┘           └──────────┘
```

#### 接线表格

| 舵机线 | 颜色 | 连接到 | 说明 |
|--------|------|--------|------|
| 信号线 | 黄色/白色/橙色 | **PB5** | PWM 控制信号 |
| 电源线 | 红色 | **5V** | 舵机电源（5V） |
| 地线 | 黑色/棕色 | **GND** | 公共地 |

#### 重要提示
- ⚠️ **信号线必须连接到 PB5**
- ⚠️ **电源线连接 5V，不要接 3.3V**
- ⚠️ **地线必须连接，否则舵机不工作**
- ⚠️ **舵机电流较大，建议使用外部 5V 电源**

#### 舵机参数
- **工作电压**: 4.8V - 6V
- **控制信号**: PWM (50Hz, 1000-2000us)
- **转向角度**: 
  - 1000us → 左极限 (约 45°)
  - 1500us → 中位 (90°)
  - 2000us → 右极限 (约 135°)

## I2C电机驱动器接线

### I2C 电机驱动器模块

#### 接线方式
```
I2C 电机驱动器          STM32F103RB
┌──────────────┐       ┌──────────┐
│              │       │          │
│   SCL        │ ─────→│   PB6    │  I2C 时钟线
│              │       │          │
│   SDA        │ ─────→│   PB7    │  I2C 数据线
│              │       │          │
│   GND        │ ─────→│   GND    │  公共地
│              │       │          │
│   VCC        │       │          │  (独立供电)
│              │       │          │
└──────────────┘       └──────────┘
       │
       │ 电机连接
       ↓
┌──────────────┐
│  M1  M2      │  4 个电机
│  M3  M4      │
└──────────────┘
```

#### 接线表格

| 驱动器引脚 | 连接到 | 说明 |
|-----------|--------|------|
| **SCL** | **PB6** | I2C 时钟线 |
| **SDA** | **PB7** | I2C 数据线 |
| **GND** | **GND** | 公共地（必须连接）|
| **VCC** | 外部电源 | 驱动器电源（通常 6-12V）|

#### I2C 参数
- **I2C 地址**: 0x34
- **通信速度**: 100kHz (标准模式)
- **支持电机数**: 4 个
- **速度范围**: -100 ~ 100

#### 电机布局
```
前方
  ↑
M1 ●─────● M2
  │       │
  │  车体  │
  │       │
M3 ●─────● M4

M1: 左前电机
M2: 右前电机
M3: 左后电机
M4: 右后电机
```

#### 重要提示
- ⚠️ **I2C 必须共地**：STM32 的 GND 必须连接到驱动器的 GND
- ⚠️ **上拉电阻**：I2C 总线需要上拉电阻（通常驱动器已集成）
- ⚠️ **电源独立**：电机驱动器使用独立电源，不要从 STM32 取电
- ⚠️ **电压匹配**：确认驱动器和电机的电压匹配

## 串口调试接线

### USB 转 TTL 模块（可选）

#### 接线方式（交叉连接）
```
USB 转 TTL              STM32F103RB
┌──────────┐           ┌──────────┐
│          │           │          │
│   VCC    │           │          │  (不连接)
│          │           │          │
│   GND    │ ─────────→│   GND    │  地线（黑色）
│          │           │          │
│   TXD    │ ─────────→│   PA10   │  交叉连接（白色）
│          │           │   (RX)   │
│          │           │          │
│   RXD    │ ←─────────│   PA9    │  交叉连接（绿色）
│          │           │   (TX)   │
│          │           │          │
└──────────┘           └──────────┘
     │
     │ USB 连接
     ↓
  电脑 USB 口
```

#### 接线表格（重要：交叉连接）

| USB转TTL | 连接到 | 线色建议 | 说明 |
|----------|--------|----------|------|
| **GND** | **GND** | 黑色 | 公共地（必须连接）|
| **TXD** | **PA10 (RX)** | 白色 | 模块发送 → STM32接收 |
| **RXD** | **PA9 (TX)** | 绿色 | 模块接收 ← STM32发送 |
| **VCC** | 不连接 | - | STM32 自己供电 |

#### 串口参数
- **波特率**: 9600
- **数据位**: 8
- **停止位**: 1
- **校验位**: 无
- **流控制**: 无

#### 重要提示
- ⚠️ **交叉连接**：TXD 连 RX，RXD 连 TX
- ⚠️ **GND 必须连接**
- ⚠️ **VCC 不要连接**：STM32 通过 ST-Link 或其他方式供电
- ⚠️ **电压匹配**：确认 USB转TTL 是 3.3V 或 5V 兼容

#### 常见 USB 转 TTL 模块
- **CH340** - 绿色 PCB，最常见
- **CP2102** - 红色 PCB，稳定性好
- **PL2303** - 蓝色 PCB，便宜
- **FT232** - 黑色 PCB，专业级

## 电源接线

### 电源系统架构

```
┌─────────────────────────────────────────────────────┐
│                    电源系统                          │
└─────────────────────────────────────────────────────┘
                         │
        ┌────────────────┼────────────────┐
        │                │                │
        ↓                ↓                ↓
   ┌─────────┐    ┌──────────┐    ┌──────────┐
   │ STM32   │    │  舵机    │    │ 电机驱动 │
   │ 3.3V/5V │    │   5V     │    │  6-12V   │
   └─────────┘    └──────────┘    └──────────┘
        │                │                │
        └────────────────┴────────────────┘
                         │
                    公共地 (GND)
```

### 电源方案

#### 方案 1: 单电源（推荐用于测试）
```
7.4V 锂电池
    │
    ├─→ 5V 稳压模块 ─→ STM32 (5V)
    │                 └─→ 舵机 (5V)
    │
    └─→ 电机驱动器 (7.4V)
```

#### 方案 2: 双电源（推荐用于实际使用）
```
5V 电源 ─→ STM32 (5V)
         └─→ 舵机 (5V)

7.4V 电池 ─→ 电机驱动器 (7.4V)
```

### 电源需求

| 设备 | 电压 | 电流 | 功率 | 说明 |
|------|------|------|------|------|
| STM32F103RB | 3.3V/5V | 100mA | 0.5W | 主控板 |
| 舵机 | 4.8-6V | 500-1000mA | 3-5W | 转向时电流大 |
| I2C驱动器 | 6-12V | 50mA | 0.5W | 驱动器本身 |
| 4个电机 | 6-12V | 2-4A | 20-40W | 根据负载变化 |
| **总计** | - | **3-5A** | **25-50W** | 建议留余量 |

### 重要提示
- ⚠️ **公共地**：所有设备的 GND 必须连接在一起
- ⚠️ **电源隔离**：电机电源和控制电源建议分开
- ⚠️ **电容滤波**：在电源输入端加 100uF 电容
- ⚠️ **防反接**：注意电源正负极，避免反接
- ⚠️ **电流余量**：电源容量建议是实际需求的 1.5-2 倍

### 接线步骤

#### 第 1 步：准备工作
- [ ] 检查所有设备是否完好
- [ ] 准备杜邦线（公对母、母对母）
- [ ] 准备电源（5V 和 7.4V）
- [ ] 准备万用表（测试用）

#### 第 2 步：连接舵机
1. 舵机信号线（黄/白）→ STM32 **PB5**
2. 舵机电源线（红）→ **5V**
3. 舵机地线（黑/棕）→ **GND**

#### 第 3 步：连接 I2C 电机驱动器
1. 驱动器 SCL → STM32 **PB6**
2. 驱动器 SDA → STM32 **PB7**
3. 驱动器 GND → STM32 **GND**
4. 驱动器 VCC → 外部电源（6-12V）

#### 第 4 步：连接电机
1. 左前电机 → 驱动器 M1
2. 右前电机 → 驱动器 M2
3. 左后电机 → 驱动器 M3
4. 右后电机 → 驱动器 M4

#### 第 5 步：连接串口（可选）
1. USB转TTL GND → STM32 **GND**
2. USB转TTL TXD → STM32 **PA10** (RX)
3. USB转TTL RXD → STM32 **PA9** (TX)
4. USB转TTL VCC → 不连接

#### 第 6 步：连接电源
1. 连接 STM32 电源（5V 或 USB）
2. 连接舵机电源（5V）
3. 连接电机驱动器电源（6-12V）
4. 确认所有 GND 连接在一起

## 接线检查清单

### 上电前检查

#### 基础检查
- [ ] 所有连接牢固，没有松动
- [ ] 电源正负极正确，没有反接
- [ ] 所有设备的 GND 已连接
- [ ] 没有短路现象

#### 舵机检查
- [ ] 舵机信号线连接到 **PB5**
- [ ] 舵机电源连接到 **5V**
- [ ] 舵机地线连接到 **GND**
- [ ] 舵机转动自如，无卡顿

#### I2C 电机驱动器检查
- [ ] SCL 连接到 **PB6**
- [ ] SDA 连接到 **PB7**
- [ ] GND 已连接
- [ ] 驱动器电源独立供电
- [ ] 4 个电机已连接

#### 串口检查（如使用）
- [ ] GND 已连接
- [ ] TXD 连接到 **PA10** (交叉)
- [ ] RXD 连接到 **PA9** (交叉)
- [ ] VCC 未连接

#### 电源检查
- [ ] STM32 电源正常（3.3V 或 5V）
- [ ] 舵机电源正常（5V）
- [ ] 电机驱动器电源正常（6-12V）
- [ ] 所有 GND 连接在一起

### 上电后检查

#### 第 1 步：上电观察
- [ ] STM32 指示灯亮起
- [ ] 没有冒烟或异味
- [ ] 没有发热异常

#### 第 2 步：舵机测试
- [ ] 舵机初始化时回中位
- [ ] 舵机能左右转动
- [ ] 舵机转动平滑

#### 第 3 步：电机测试
- [ ] 电机能前进
- [ ] 电机能后退
- [ ] 电机能停止
- [ ] 4 个电机都正常

#### 第 4 步：串口测试（如使用）
- [ ] 串口助手能打开 COM 口
- [ ] 能收到调试信息
- [ ] 信息显示正常，无乱码

### 故障排查

#### 舵机不动
1. 检查 PB5 连接
2. 检查舵机电源（5V）
3. 检查 GND 连接
4. 用万用表测量 PB5 是否有 PWM 信号

#### 电机不动
1. 检查 I2C 连接（PB6, PB7）
2. 检查 GND 连接
3. 检查驱动器电源
4. 检查电机连接

#### 串口无输出
1. 检查 TX/RX 是否交叉连接
2. 检查 GND 连接
3. 检查波特率（9600）
4. 检查 COM 口号

#### 系统不稳定
1. 检查电源容量是否足够
2. 检查所有 GND 是否连接
3. 添加电源滤波电容
4. 检查接线是否松动
